# TMGL Android Build Guide

## Architecture

The Android app is a **native Kotlin/Jetpack Compose application**, NOT a Capacitor WebView wrapper.

- **Language:** Kotlin 2.0.21
- **UI:** Jetpack Compose + Material3
- **Backend:** Supabase Kotlin SDK (direct PostgREST)
- **Min SDK:** 24 (Android 7.0)
- **Target SDK:** 35 (Android 15)

## Build Requirements

| Requirement | Version |
|-------------|---------|
| Android Studio | Latest stable |
| JDK | 21 |
| Gradle | 8.14.3 (via wrapper) |
| Android SDK | API 35 |
| Kotlin | 2.0.21 |
| Compose BOM | 2024.12.01 |

## Setup

### 1. Clone Repository
```bash
git clone https://github.com/abdullahafsar5002/TMGL/
cd TMGL/android
```

### 2. Create local.properties
```properties
# Android SDK (auto-generated by Android Studio)
sdk.dir=C\:\\Users\\YourUser\\AppData\\Local\\Android\\Sdk

# Supabase credentials
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

### 3. Open in Android Studio
- File > Open > Select `android/` directory
- Wait for Gradle sync

## Build Commands

### Debug APK
```bash
./gradlew assembleDebug
```
Output: `app/build/outputs/apk/debug/app-debug.apk`

### Release APK
```bash
./gradlew assembleRelease
```
Requires signing configuration (see below).

### App Bundle (AAB)
```bash
./gradlew bundleRelease
```
Output: `app/build/outputs/bundle/release/app-release.aab`

## Signing

### Debug Signing
Uses Android Studio debug keystore automatically.

### Release Signing
Create `android/key.properties`:
```properties
storeFile=C\:/path/to/your-keystore.jks
storePassword=your-password
keyAlias=your-alias
keyPassword=your-password
```

**NEVER commit this file to version control.**

### Generate Release Keystore
```bash
keytool -genkey -v -keystore tmgl-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias tmgl
```

## ProGuard/R8

Release builds enable minification:
- `minifyEnabled true`
- `shrinkResources true`
- ProGuard rules: `app/proguard-rules.pro`

## Permissions

| Permission | Purpose |
|------------|---------|
| INTERNET | Supabase API calls |
| ACCESS_NETWORK_STATE | Network status |

## Network Security

- HTTPS enforced for all Supabase communication
- No cleartext traffic allowed
- `allowBackup="false"` prevents data extraction

## Testing

### Unit Tests
```bash
./gradlew test
```

### Instrumented Tests
```bash
./gradlew connectedAndroidTest
```

## Known Limitations

- No offline scoring support (requires network)
- No push notifications
- No biometric authentication
- No deep linking configuration
