# TMGL Deployment Guide

## Web/PWA Deployment (Vercel)

### Prerequisites
- Vercel account connected to GitHub repository
- Supabase project with environment variables

### Environment Variables
Set in Vercel dashboard:
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### Deployment Steps
1. Push to `main` branch
2. Vercel auto-deploys on push
3. Build command: `npm run build`
4. Output directory: `dist/`
5. SPA rewrites configured in `vercel.json`

### PWA Installation
- Users can install from browser address bar
- Works on Android Chrome, iOS Safari 16.4+, Desktop Chrome/Edge
- Auto-updates when new version deploys

## Android Build

### Prerequisites
- Android Studio (latest stable)
- JDK 21
- Android SDK with API 35
- `android/local.properties` with Supabase credentials

### local.properties Setup
```properties
# Android SDK path (auto-generated by Android Studio)
sdk.dir=C\:\\Users\\YourUser\\AppData\\Local\\Android\\Sdk

# Supabase credentials
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your-anon-key
```

### Debug Build
```bash
cd android
./gradlew assembleDebug
```
Output: `android/app/build/outputs/apk/debug/app-debug.apk`

### Release Build
```bash
cd android
./gradlew assembleRelease
```
Requires `android/key.properties` with keystore configuration.

### App Bundle (AAB) for Play Store
```bash
cd android
./gradlew bundleRelease
```
Output: `android/app/build/outputs/bundle/release/app-release.aab`

### Signing Configuration
`android/key.properties`:
```properties
storeFile=path/to/your-keystore.jks
storePassword=your-store-password
keyAlias=your-key-alias
keyPassword=your-key-password
```

**NEVER commit `key.properties` to version control.**
