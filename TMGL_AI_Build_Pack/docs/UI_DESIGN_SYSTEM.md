# TMGL UI Design System

## Brand direction

Premium golf + competitive sports.

Visual language:
- deep golf-green atmosphere
- charcoal/dark surfaces where appropriate
- white content surfaces
- restrained gold accent
- strong typography
- clean cards
- score-focused layouts

Avoid:
- excessive gradients
- excessive glassmorphism
- clutter
- tiny touch targets
- fake 3D dashboard graphics

## Mobile-first priorities

Golfers will often use the app outdoors.

Score entry should:
- require minimal typing
- have large controls
- show current hole clearly
- show running total
- support previous/next
- preserve unsaved local state where safe
- confirm final submission

## Main navigation

Public:
Home / League / Players / Teams / Tournaments / Leaderboard / Results

Player:
Home / Matches / Score / Leaderboard / Profile

Admin:
Dashboard / League / Competition / Golf / Reports / Communication / System
